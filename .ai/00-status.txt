SOMA — TECHNICAL BASE (read this first, together with GitHub Issues)

WHAT IT IS
Compact self-learning Minecraft agent. One world, one agent, no parallel worlds.
Decision model ~3.4M params (target budget 10M), vector observations, no images,
no LLM in the game loop. Reward = multi-signal. Replay buffer on disk.
Spec source: idea.txt on the user's desktop (desktop file, not in repo).

PROTOCOL (bot <-> brain), schema v1
frame -> flat float32 vector, 3450 dims:
  self 32 | grid 512*6 | ent 12*10 | inv 41*4 | ev 10*5 | meta 12
all values relative to the player, rotated into the player's frame
(translation + rotation invariant). Categorical ids go through FIXED hashed
embeddings (4096 blocks, 2048 items, 1024 entity names) - mods cannot shift the
feature space.
candidate = one admissible action (mine/goto/attack/use/place/equip/eat/drop/
jump/wait/stop). Bot advertises <=48 candidates, brain answers with an INDEX.

MODEL (agent/model.py)
encoder 3450->768->192 | temporal 6*192->384->192 |
Q head (192+16)->128->1 per candidate | V head | aux dynamics head
3,428,097 params, fp32, ~14 MB. Encoder is trained ONLY by the auxiliary loss
(predict next latent); the RL loss uses detached latents. Trainer publishes
model.npz.tmp.<pid> + os.replace; brain reloads on mtime.

REWARD (agent/reward.py)
new block/item type, new chunk (novelty, log-damped), damage, death (-3),
idle, time cost (-0.005/step), all clipped to +-3.
