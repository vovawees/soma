SOMA — ЛОКАЛЬНАЯ КОПИЯ (читай первым)

Это полный исходник проекта: ИИ-ядро + серверный мод + адаптер для ванильных
серверов + скрипты. История git сохранена (6 коммитов).

БЫСТРЫЙ ЦИКЛ РАЗРАБОТКИ (без рестарта MC-сервера)
Мод слушает 127.0.0.1:8788 на VPS. Мозг подключается к нему как клиент.
Значит ИИ-часть можно крутить локально, не трогая сервер:

  # на твоём компе
  ssh -L 8788:127.0.0.1:8788 -i ~/.ssh/oci_a1 opc@<VPS_IP>   # туннель
  python3 -m venv .venv && .venv/bin/pip install -r agent/requirements.txt
  cd agent && SOMA_IPC_PORT=8788 ../.venv/bin/python brain.py

  # обучение отдельным процессом
  cd agent && ../.venv/bin/python trainer.py

Изменения в agent/ видны сразу. Изменения в mod/ требуют пересборки и рестарта.

СБОРКА МОДА
  bash mod/build.sh
Мод собирается javac'ом против пропатченных классов Minecraft, которые уже лежат
в libraries/ самого сервера. Варианты:
  - собрать на VPS:  bash scripts/deploy_mod.sh   (соберёт, поставит, перезапустит)
  - собрать локально: нужен локальный NeoForge-сервер 1.21.1, тогда
        MC_DIR=/path/to/server bash mod/build.sh
Требуется JDK 21 (java-21-openjdk-devel).

ВАЖНО ПРИ ПЕРЕНОСЕ (см. полный список в .ai/00-status.txt)
  1. Классpath в mod/build.sh исключает libraries/net/minecraft/server/1.21.1* —
     эти промежуточные jar'ы перекрывают маппированные классы и сборка падает
     с "cannot find symbol" на getLevel().
  2. FakePlayer не тикает: Entity.tickCount остаётся 0, а LivingEntity.hurt()
     отвергает ВЕСЬ урон "недавно созданной" сущности. Обязательно зови
     player.baseTick() каждый тик, иначе мобы бьют, а хп не меняется.
  3. Entity.setInvulnerable(false) — отдельный флаг от Abilities.invulnerable,
     проверяется первым. Чистить оба.
  4. placeNewPlayer перечитывает NBT игрока с диска — выдавай стартовый набор
     ПОСЛЕ него, иначе инвентарь сотрётся.
  5. np.savez дописывает .npz к имени без расширения — временное имя чекпоинта
     должно заканчиваться на .npz.
  6. Индекс действия резолвится по seq кадра: мозг шлёт "s", мод держит
     последние 12 списков кандидатов. Без этого индекс применяется к чужому
     списку и агент делает не то действие.

ЧТО УЖЕ РАБОТАЕТ (проверено на живом сервере)
  настоящий игрок в табе, мобы таргетят и бьют, урон идёт, падение/лава/голод/
  реген, прогрессивная добыча с учётом инструмента, свой A*, плавание, спринт,
  подбор дропа, стартовый набор, чистка стоеек, IPC, обучение с чекпоинтами.

  - шифт-крафт, лук/стрелы, алмазы, постройки
